# Latest Update: Automatic Invoicing Feature

**Status**: Completed

**Changes Made:**
1.  **"Generate Automatic Invoice" Checkbox**: On the final "Review" step of the Student Admission form, you will now see a checked-by-default option to immediately generate an invoice.
2.  **Automatic Fee Seeding**: When you admit a student (e.g., to Grade 1), if no fee structure exists for that grade, the system will now **automatically seed default fee structures** for you before creating the invoice.
3.  **Invoice Creation**: Upon successful admission, an invoice for the current term will be created instantly.

Please check the updated `walkthrough.md` for verification steps.
